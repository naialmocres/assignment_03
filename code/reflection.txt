In this assignment, I learned how Streamlit's rerun execution model operates whenever a UI widget returns a new value. State management required using st.session_state to initialise once so metrics persisted across reruns, alongside guard clauses to prevent premature execution. I struggled initially on the third Streamlit app with determining which module-level import statements were necessary and handling bytes vs. text when using decode on file inputs. Managing button-triggered flow and capturing each widget's return value ultimately allowed me to output unit counts cleanly using st.metric. Moving forward, I will practice setting up multi-page session state patterns and adding robust try-except error handling to build more resilient apps.
